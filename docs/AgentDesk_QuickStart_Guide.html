AgentDesk 极简上手指南

—— 专为电脑小白设计的 AI 桌面智能助手教程

欢迎使用 AgentDesk！这是一款运行在您本地电脑上的 AI 助手。它不仅能回答问题，还能在您的授权下直接为您整理文件、编写代码。本指南将帮助您在 3 分钟内完成配置并开始体验。

第一步：配置 DeepSeek API（激活余额）

AgentDesk 采用本地直连 DeepSeek 官方接口的设计，因此需要配置您的专属“API Key”（相当于一把充值钥匙），这能确保您只为自己实际的消耗付费，杜绝第三方中间商赚差价。

1

注册并获取 API Key

用电脑浏览器打开 DeepSeek 开放平台官网：platform.deepseek.com。注册账号后，点击左侧菜单的 “API Keys”，点击 “创建 API Key”，将其拷贝并妥善保存。

2

在平台中进行充值

在 DeepSeek 平台左侧选择 “充值” (Usage)，支持支付宝或微信。首充极低（例如 10 元人民币），可支撑数十万字对话，使用成本极低。

3

在 AgentDesk 中保存 Key

启动 AgentDesk，点击主界面右上角的齿轮图标（设置）。在弹出的面板中选择“API与模型”，将刚刚复制的 API Key 粘贴到对应的输入框中，点击底部的保存按钮。

4

确认余额显示

保存成功后，主界面顶部栏会自动出现一个精美的“余额”胶囊，实时显示您的账户剩余额度。如果余额更新出来，说明连接已成功，您可以立即开始和 AI 聊天了！

第二步：核心功能与使用方法

配置好 Key 后，您可以体验以下三种便捷交互：

A

日常对话与问题解答

在底部输入框输入您遇到的任何难题（如写一封公文邮件、修改 Excel 公式、制定旅游计划等），点击发送或按回车。AgentDesk 会为您快速梳理答案。

B

一键语音听写转文字

懒得打字？点击输入框右下角的 “录音麦克风” 按钮，大声说出您的问题，系统会自动启动听写功能，并将您的语音高精准度地转化为文字输入。

C

安全授权代码与命令执行

当您让 AI 执行如“帮我把桌面所有的图片移动到新建文件夹”等系统命令时，AI 会弹出一个“操作确认卡片”。只有在您确认并点击“同意执行”（Proceed）后，它才会真正动手，绝对安全可控。

第三步：AgentDesk 平台核心优势

比起市面上其他云端 AI 网页，AgentDesk 具有得天独厚的四项本地优势：

本地隐私安全 (数据防泄露)

您的所有 API Key、历史对话文件、以及代码指令全部加密保存在您本地电脑。不经过任何中间云端服务器，保障绝对隐私。

实时余额监控 (花多少看得见)

独创顶部栏实时余额胶囊。每次对话扣减明明白白。支持点击一键安全跳转至官方充值页，防止过度透支或扣费不清。

真正的动手能力 (代码沙箱)

不同于只能清谈的网页版 AI。它可以调用本地命令行、编写脚本、整理文件。在您的指尖批准下，帮您完成真实的电脑操作。

极致精简 (无感后台运行)

抛弃了复杂的命令行配置。提供一键安装包和免安装便携版。双击即用，界面现代流畅，完美兼容浅色与暗色模式。
